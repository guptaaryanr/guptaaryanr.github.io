01

Inverse problems · PDE simulation · Devito

WaveSleuth-Devito

Inverse Wave Playground v1.0

2026

I built this while learning Devito because I usually understand a framework only after I have tried to make something end to end with it. The setup is small on purpose. Hide a structure in a 2D acoustic medium, collect sparse traces, and see what you can recover.

Inside it
Several acquisition geometries, a real Devito forward model, simple inversion baselines, blind challenges, active sensing, uncertainty summaries, scoring, and release checks.
Scope
Not a seismic package and not a claim about field scale imaging. It is a small inverse problem sandbox that I can break without waiting three days for a run.
1 hidden medium→2 sparse traces→3 invert→4 reconstruct + score

The actual v1.0 loop. Sources and receivers are sparse on purpose. Ambiguity is part of the game.

02

Nonlinear dynamics · Scientific computing · Trajectory analysis

Trajectory-Only Structural Regime Detection

2026

I wanted to know whether a detector could pick up structural change without being told what kind of change it should expect. I kept the governing equations, regime labels, and transition definitions away from it and only gave it trajectories across an ordered parameter sweep.

What it gets
Trajectories and the order of the parameter sweep. From those it builds a fixed set of indicators, a structural score, and an extracted boundary.
How I checked it
The qualitative boundary is computed separately with model specific information and only brought back at evaluation. On the two systems in the paper, the structural boundary appears earlier. The claim stops there.

03

Scientific ML evaluation · Thermodynamics

ThermoBench-Consist v1.0

2025

I built ThermoBench after a GNN surrogate for vapor liquid equilibrium fooled me in a fairly instructive way. Ordinary prediction error looked acceptable. Inside the thermodynamic calculation, it fell apart. The useful question was not whether the average error was low. It was whether the learned surface still behaved like thermodynamics.

Basic test
Before a learned equation of state goes anywhere near a CFD or VLE solver, make it pass a few cheap physical consistency checks.
The catch
Critical and spinodal regions need guardrails. Without them, the diagnostic starts flagging perfectly reasonable behavior as a failure.

LLM evaluation tooling · CI

Costgate

CI cost regression gate for LLM inference

2026

An LLM change can get more expensive while all the normal tests still pass. The API returns, the output looks fine, and the bill quietly moves in the wrong direction. Costgate gives that kind of regression a place in CI.

Compared
Baseline and candidate runs over the same suite. It looks at cost per valid success, token use, task success, latency, repeat variability, and explicit thresholds.
Kept deliberately small
A giant eval platform. The policy is a file, the artifacts are inspectable, and the useful output at the end is still just pass, warn, or fail.
